# Sales Customization

Custom Odoo module to enhance Sales and Product workflows.

## 📦 Features

- Adds custom fields to:
  - Product Template (Item Master)
  - Sales Orders
  - Partners
- Custom views for:
  - Product Kanban
  - Sales Order
- Reports included:
  - Proforma Invoice
  - Commercial Invoice
  - Packaging List
  - Order Sheet
  - Export Order
  - BL Instruction
  - Financial Report
- Security group access control
